# Website Traffic Analysis using Power BI

## Project Overview
This project analyzes website traffic data using Microsoft Power BI to understand traffic patterns, user engagement, and channel performance.

## Objectives
- Analyze website traffic trends.
- Compare traffic sources and channels.
- Identify high-performing traffic categories.
- Create interactive dashboards for data-driven decision-making.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Project Workflow
1. Imported the website traffic dataset into Power BI.
2. Cleaned and transformed the data using Power Query.
3. Created measures using DAX where required.
4. Designed interactive charts, cards, and slicers.
5. Analyzed traffic patterns and presented insights through a dashboard.

## Project File
The `.pbix` file contains the Power BI report and its data model.
